# SIH-26010 — Rural Land Resurvey Triage Platform

## Executive Summary
A comprehensive full-stack automated land resurvey triage platform designed for the Smart India Hackathon (SIH-26010). The system modernizes legacy rural land administration by autonomously reconciling historical paper cadastral maps against modern sub-meter satellite/drone imagery.

## Core Architectural Pipeline
The platform processes cadastral land parcels through an automated 9-phase lifecycle:
1. **Seed & Setup**: Ingestion of real cadastral surveys (Bhu-Naksha), ESRI high-resolution satellite imagery tiles, and simulated legacy paper revenue scans.
2. **AI Extraction**: Multi-tier boundary segmentation using computer vision (Canny contours), spectral feature analysis (bunds, roads, canals), and ground observations.
3. **Georeference**: Least-squares 6-parameter affine transformation mapping historical paper scans to true geographic coordinates using Ground Control Points with metric RMSE evaluation.
4. **Polygon Matching**: IoU-based spatial matching classifying parcel relationships into `ONE_TO_ONE`, `SPLIT`, `MERGE`, and `NO_MATCH`.
5. **Reconciliation**: Metric evidence compilation computing observed area, Average Symmetric Boundary Distance (ASBD), vegetation/shadow occlusion, and ground feature support ratios.
6. **Deterministic Triage**: Hierarchical waterfall rule evaluation classifying each parcel into `CLEARED`, `FLAGGED`, or `INSUFFICIENT_EVIDENCE` with auditable reason codes.
7. **KPIs & Audit Ledger**: Real-time operational dashboard metrics (false-clear rate, RTK reduction %) and immutable SHA-256 hash-chained version ledger (US-5.3).
8. **REST API**: Production-grade FastAPI service exposing PRD Appendix A compliant endpoints and static spatial tile assets.
9. **Interactive Frontend**: React / Vite / MapLibre application featuring dual-layer visual map comparison, interactive vertex editing, and SRO sign-off workflows.
